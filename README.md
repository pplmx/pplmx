## 🧭 About Me

- 🦀 Crafting tools & systems in **Rust** — git hooks ([husky-rs](https://github.com/pplmx/husky-rs)), networking ([ip-tools](https://github.com/pplmx/ip-tools)), and a lightweight LLM inference engine ([vllm-lite](https://github.com/pplmx/vllm-lite))
- 🧠 Exploring **LLM & ML** — from hands-on [llm playground](https://github.com/pplmx/llm) to CUDA parallel algorithms ([nova](https://github.com/pplmx/nova))
- 🧰 Maintaining [**@x-pt**](https://github.com/x-pt) — *X Project Template*, scaffolding awesome projects across languages in no time
- ☁️ Living in the **Cloud Native** world: Kubernetes, Docker, OpenStack
- 🌌 `Location: Everywhere & Nowhere` — exploring the unknown world with [Aurora](https://github.com/pplmx/aurora)
- ✍️ Writing occasionally at [pplmx.github.io](https://pplmx.github.io)
